# Multi_AI_for_meeting – Meeting Decision Extractor (MVP)

Hệ thống nhận transcript cuộc họp tiếng Việt (`.txt`, `.vtt`) và trả về danh sách có cấu trúc:
quyết định cuối cùng, việc cần làm, vướng mắc, yêu cầu, vấn đề chưa chốt, tri thức mới —
mỗi mục có trích dẫn câu gốc, trạng thái và lịch sử thay đổi.
